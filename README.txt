R code for the applications in "A Bayesian self-starting Hotelling T^2 for online multivariate outlier detection" by K. Bourazas, A. Batsidis and P. Tsiamyrtzis.

Each script runs one application and saves its figure as a PDF in the working directory:

Application BSSH - z-scores.R
Application BSSH - cost.R
Application BSSH - water treatment.R

The water treatment script needs the file water-treatment.data in the working directory. The data come from the UCI Machine Learning Repository (Poch, 1993, https://doi.org/10.24432/C5FS4C).
